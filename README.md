# Corel Textile Automation

Sistema de automatización textil para CorelDRAW usando Python y COM.

## Funciones actuales

- Conexión automática con CorelDRAW
- Apertura de archivos .cdr
- Generación automática de pedidos
- Filtrado de tallas
- Duplicación automática de páginas y moldes

## Tecnologías

- Python
- pywin32
- CorelDRAW COM API
